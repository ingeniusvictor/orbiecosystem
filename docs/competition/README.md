# Competition Content Foundation

This folder is the source of truth for the ORBI PVMetrics IA - Climate Recovery Edition competition content.

## Purpose

The documents in this folder define the canonical narrative, claims policy, proposed route structure, SEO requirements, accessibility requirements, analytics boundaries and QA checklist for the AI for Climate Innovation Factory 2026 submission.

They exist before any public interface changes so future pages and components can be built from approved content instead of copying strategic text directly into visual components.

## Document Relationships

- `BASELINE_MANIFEST.md` records what is verifiable in the repository at the start of this module.
- `COMPETITION_BRIEF.md` explains the submission, product, category and boundaries.
- `CONTENT_CANON.md` stores approved strategic text.
- `CLAIMS_REGISTER.md` controls what may be published and what requires evidence.
- `ROUTE_SPEC.md` describes future routes without implementing them.
- `SEO_SPEC.md` defines future metadata requirements.
- `ACCESSIBILITY_SPEC.md` defines quality expectations for public pages.
- `ANALYTICS_SPEC.md` documents measurement boundaries and privacy rules.
- `QA_CHECKLIST.md` is the acceptance checklist for future competition work.

## Canonical Content Rules

- Do not change canonical text without explicit approval.
- Do not invent metrics, customers, partnerships, pilots, investment figures or climate results.
- Keep facts, estimates, simulations, projections and future vision separate.
- Label synthetic demo data as Synthetic Data.
- Keep the principle: The AI recommends; the operator decides.

## Implementation Rule

Visual components must not contain independent copies of strategic competition text. Future UI should consume or mirror the centralized competition content registry so the public interface stays aligned with these documents.
